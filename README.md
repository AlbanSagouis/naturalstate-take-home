# Natural State take-home

Take-home for the Senior Data Scientist role at Natural State: BirdNET per-species thresholds and a
herbaceous vegetation QA/QC report, each with a handoff to the Tech team.

Work in progress. The full README (TL;DR, deliverables, how to reproduce, process, skills, time
statement) is written at the end, see the issue list on GitHub for the decision trail.

Code is MIT licensed. The data in `data/raw/` belongs to Natural State and is anonymised (confirmed by Natural State); it is committed unchanged, with hashes in `data/raw/MANIFEST.sha256`. The brief, the SOPs and the Wood & Kahl paper are kept local and are not in this repository.
